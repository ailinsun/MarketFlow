# Design decisions

One file per decision that is hard to reverse or easy to get wrong on a second
reading. Each states the decision, what it rules out, and what would have to be true
for it to be wrong.

[docs/EVOLUTION.md](../EVOLUTION.md) covers how the project arrived at these; this
directory records what was decided.

|---|---|

| [003](003-unset-means-closed.md) | Unset means closed |
