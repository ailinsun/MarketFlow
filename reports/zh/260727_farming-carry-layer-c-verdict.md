## 0. 判决

**DEMOTE — 层 C 除名。** tail-adjusted 年化 **−191.9%** (CI95 [−278.3%, −110.0%]), 远低于
预登记的 4% 除名线。尾部事件 **n=287** ≥ 100, 样本充足, 不是「数据不够」而是「测出来是负的」。
2,000 次 bootstrap 重采样 **100% 为负** —— 没有一次抽样让它转正。

判据在跑数之前写死在仪器 docstring 里, 未因结果改动一个字。

## 0.1 修订说明 (2026-08-05) — 首版两处错误

首版 (07-27) 的判决方向正确, 但有两处必须更正:

**① 年化的量级错了: −60.7% → −191.9%。** 首版用 `end_date` 当结算时间算持有期。
`whale_report_dataset.settlement_ts` (C5, 08-04 实证) 明确禁止这一点 —— endDate 是**计划
事件时间**不是结算时间, 两个方向都会偏。本样本以体育盘为主, endDate 系统性**晚于**真结算
(closedTime), 于是持有期被高估约 3 倍 (均值 6.02d → **1.90d**, 中位 2.13d → **0.173d**),
年化的绝对值被同比例压小。改用权威 `settlement_ts` 后 98.2% 的结算时间来自 `closedTime`。
**每笔净回报 −1.00% 完全不受影响** (它不含时间维度), 各价带/TTC 的尾部差也不受影响 ——
所以判决与全部机制结论不变, 变的只是年化这一个量的刻度。

**② 「260726 报告的 +0.22% 在独立性修正后符号翻转」这个说法是错的 —— 撤回。**
用报告自己的 `agg_clustered` (它在 referenced section 已用于总量) 在重建的完整样本上复算 ≥0.90 价带:

| 口径 | n | 净回报 | 2SE |
|---|---|---|---|
| 逐笔等权 (报告 referenced section) | 32,864 | **+0.289%** | ±0.177% |
| **按市场聚类 (报告 referenced section 自己的方法)** | 9,475 | **+0.134%** | **±0.272%** |
| 每结局首笔 | 9,475 | −0.173% | ±0.329% |

**符号没有翻转。** 正确的结论是: 聚类后点估计**减半且置信区间盖住 0** —— 这一格
**不能被称为「为正」, 也不能被称为「为负」, 它统计上与 0 不可区分**。首版说它「翻负」
是把一个不显著的负点估计当成了结论, 犯的正是被批评的那类错。首版那个 −0.63% 是在旧
meta 缓存 (9,854 市场) 上算的, 而重建后是 17,488 市场 —— 旧缓存漏掉的样本不是随机的。

对层 C 判决**无影响**: 层 C 问的是「按一条可预先写下的规则买入」, 报告那格问的是
「跟着鲸鱼已发生的打印买」, 两个样本框不同, 结论也不冲突 (前者显著为负, 后者不显著)。

## 1. 预登记判据 (跑数前写死)

| 项 | 内容 |
|---|---|
| 入场规则 | 每个 (market, token), 价格路径**首次**进入 [0.90, 1.00) 时买 $1, 持有到结算, 每 token 至多一笔 |
| 判据量 | real 费率 · taker 口径 · capital-days 年化 = `Σpnl / Σ(capital×holding_days) × 365` |
| PROMOTE | 年化 ≥ 8% **且** 尾部事件 n ≥ 100 → 提「进 paper forward」方案 |
| DEMOTE | 年化 < 4% → 层 C 除名, 更新 spec |
| HOLD | 其余 |

三个口径也一并预登记, 理由写在 docstring:

1. **主情景取 taker 费不取 maker**。farming 的自然形态是挂 bid 当 maker (referenced section: maker 付 0 费),
   但 referenced section 实测我们自己 **91% 的 intent 挂到过期不成交** —— 「挂得上单」是未验证前提。
2. **尾部事件按独立结局计, 不按打印笔数计**。同一市场几万笔打印共享同一个结局。
3. **年化取 capital-days, 不取单笔复利外推** (referenced section: 0.93 天外推 392.7x 不构成判决)。

## 2. 主结果

样本框 = market_meta_cache 的 **9,854 个已结算市场** × CLOB prices-history (100 万个价格点,
取数零失败), 二元互补导出另一腿。可判入场 **n = 7,516**。

| | real (判据) | flat 0.07 | maker 0 费 |
|---|---|---|---|
| 每笔净回报 | **−1.001%** | −1.001% | −0.848% |
| capital-days 年化 | **−191.9%** | −192.0% | −162.6% |
| CI95 | [−278.3%, −110.0%] | [−278.4%, −110.2%] | [−248.7%, −81.0%] |

**连 maker 零费的天花板情景都是 −162%。** 费用不是问题, 尾部才是 —— 实测 98.6% 的市场
开着费率 (0.05 占 22,767 / 0.07 占 7,221 / 0.04 占 1,043), 但把费率整个归零也救不回来。

| 量 | 值 |
|---|---|
| 尾部事件 (结算 0) | 287 / 7,516 = **3.82%** (Wilson CI95 [3.41%, 4.28%]) |
| 市场定价隐含尾部率 (1 − 均价) | **3.06%** |
| 实证 − 隐含 | **−0.75pp** ← 全部亏损来源 |
| 均入场价 | 0.9694 |
| 中位持有 | **0.173 天 (4.2 小时)**, 均值 1.90 天 |
| 结算时间来源 | closedTime 7,379 · closedTime 早于末笔成交 131 · 末笔成交 6 (**endDate 0**) |
| 作废结算 (0.5) | 7 笔, 单列不计入尾部 |
| bootstrap 为负的比例 | **100%** |

**机制一句话**: 近确定区的票不是「便宜的保险」, 是**定价偏贵的保险** —— 市场对
「热门翻车」的定价系统性低于实际发生率 0.75 个百分点, 而在 0.97 的价位上, 0.75pp 的
尾部误差就吃掉全部 carry (0.97 的票赢了只付 3.1%)。

| TTC | n | 实证尾部 | 隐含 | 差 | 每笔 |

## 4. 三道验证 — 负结论不是数据假象

| 验证 | 问题 | 结果 |
|---|---|---|
| **互补导出腿** (真拉 token[1] 回核) | 省一半调用的假设成立吗 | 60 市场 / 1,320 点比对, 3 点偏差且最大 0.005, **进带判定 0 处不一致** |
| **可成交性** (对 tape 真实逐笔) | 路径价买得到吗 | 431 个入场落在 tape 覆盖市场内, **77.5%** 在其后 1 小时有真实成交, **75.2%** 有成交落在路径价 +1 分以内; 前向 VWAP − 路径价中位 **−0.0005** ≈ 0 |
| **独立样本框** (鲸鱼大额 BUY 打印) | 换个完全不同的样本还负吗 | n=6,234 独立结局, 尾部 2.65% vs 隐含 2.71%, 每笔 **−0.097%** — 点估计为负但**不显著** |

鲸鱼样本 (每笔 −0.10%) 比路径样本 (−1.00%) 好得多, 且**统计上与 0 不可区分**。差距的来源是
选择: 鲸鱼只在自己挑过的盘上大额进场, 路径样本包含每一个曾经摸到 0.90 的票 —— 包括那些
摸到就掉头的。我们要预先写下入场规则才能交易, 而「鲸鱼挑过的盘」不是一条可以预先写下的规则。

> **可成交性一栏是首版 (07-27) 的数**。tape (194 万笔逐笔) 已在 referenced section 的清理里删除, 本次
> 无法重跑。它只支撑「路径价可成交」这一条辅助结论, 不进判据; 如需重验须重新采集 tape。

## 5. 260726 报告的 ≥0.90 那一格 — 不是「翻负」, 是「不显著」

已发布的 [260726 巨鲸报告](../en/260726_polymarket-whale-behavior-report.md) referenced section 称 ≥0.90 是
**唯一费后为正的价带 (+0.22%)**。用报告**自己的代码** (`follow_returns` / `agg_returns` /
`agg_clustered`) 在重建的完整样本 (17,488 市场 meta) 上复算:

| 口径 | n | 净回报 | 2SE | 与 0 的关系 |
|---|---|---|---|---|
| 逐笔等权 (报告 referenced section 用的) | 32,864 | **+0.289%** | ±0.177% | 显著为正 |
| **按市场聚类 (报告 referenced section 自己已在用的方法)** | 9,475 | **+0.134%** | ±0.272% | **不可区分** |
| 每结局首笔 | 9,475 | −0.173% | ±0.329% | **不可区分** |

**报告的算术没有错, 结论也不需要反转 —— 需要的是一个限定。** 同一市场里的多笔打印共享
同一个结局, 不是独立观测; 报告在 referenced section 对总量已经用了市场级聚类 (−3.11% → −1.22%), 只是
referenced section 那张价带表没做同样的处理。补上之后, ≥0.90 的点估计**减半且置信区间盖住 0**。

⟹ 准确的说法是「**唯一没有明确为负的价带**」, 而不是「唯一为正的价带」。
差别不是修辞: 前者不能用来支撑任何收益主张, 后者可以 —— 而数据只支持前者。

其余价带的聚类值 (同一次复算): <0.20 −12.1% · 0.20–0.50 −6.72% · 0.50–0.80 −0.47% ·
0.80–0.90 **+2.03% ±1.38%**。**单调性这个主发现在聚类后依然成立且更强**, 只是最右两格的
位置变了 —— 0.80–0.90 才是聚类口径下唯一显著为正的一格。

> **首版 (07-27) 在这一节写的是「符号翻转, 报告结论不成立」—— 那是错的, 已撤回。**
> 当时的 −0.63% 算在旧 meta 缓存 (9,854 市场) 上, 而重建后是 17,488 市场; 旧缓存漏掉的
> 样本不是随机的。更根本的错是: 把一个置信区间盖住 0 的负点估计当成了结论。

## 6. 容量与 vault 库存协同 (即便策略成立也受限的两个数)

容量口径来自 tape 真实逐笔 (493 市场 / 196 天 / 2025-12-08 → 2026-07-27), 只对这个样本框成立,
未外推全市场。关键区分: data-api 的 `side` 是 **taker 方向** —— taker=SELL 的量才是挂单
farmer 能被动接到的量。

| | 日均成交额 | 取 10% 不冲击 | × 均持有 1.90d → 稳态 AUM |
|---|---|---|---|
| maker 侧 (接主动砸盘) | $591,623 | $59,162/日 | **$112k** |
| taker 侧 (主动扫单) | $1,166,445 | $116,644/日 | **$222k** |

> 稳态 AUM = 日可部署额 × 平均持有天数。持有期按 referenced section 修正后缩短约 3 倍, 容量上限
> 同比例下降 —— **这条即使层 C 成立也是硬约束**: 这门生意装不下多少钱。
> 日均成交额本身是首版从 tape 算的 (tape 已删, 见 referenced section 注), 未重算。

按价带看, ≥0.90 的成交额高度集中在 0.99–1.00 (日均 SELL $490k, 占 83%) —— 也就是集中在
carry 最薄的那一段。0.95–0.98 那段只有日均 $37.5k。

**vault 库存协同**: maker sampler 的 30 个在做盘中, **8 个 (26.7%)** 在 tape 里有 ≥0.90 带成交量
(该重叠内 ≥0.90 成交额 $3.54M)。重叠可测的部分不高, 且只在 tape 覆盖范围内可测 —— 但这条
现在是**空问题**: 层 C 已除名, 库存协同没有可协同的对象。若层 A 将来要给自然积累的
near-certainty 库存定处置规则, 本仪器的价带/TTC 表就是那个规则的依据 (结论是: **持有到结算不
划算, 该在近确定区卖出而不是买入**)。

## 7. 可实现性 (补充口径, 不参与判据)

capital-days 年化假设资本随时可再投, 但没检查有没有那么多机会。固定 AUM 按时间顺序回放
(单笔 ≤ AUM 2%, 且 ≤ 该市场成交额 10%), 分母用日历时间:

| AUM | 年化 | 资本利用率 |
|---|---|---|
| $25k | −325.3% | 93.2% |
| $100k | −376.7% | 91.7% |
| $1M | −236.9% | 92.8% |

> 修正持有期后这一节的结论**反转了**: 首版资本利用率只有 ~18% (机会不够摆满), 修正后是
> **~92%** —— 因为每笔的占用时间短了 3 倍, 同样的机会流可以让资本一直在场。于是
> 「摆不满所以一年只亏 5–21%」这个缓冲**不存在**: 资本几乎满仓地重复做一件每笔亏 1% 的事,
> 日历年化就跟 capital-days 年化同量级了。
>
> 三个 AUM 的年化非单调 ($1M 反而好于 $100k) 是深度闸的副作用 —— 大 AUM 撞上单市场
> 10% 成交额上限, 被迫跳过一部分机会, 其中包含一部分亏损机会。这是口径产物不是规模优势。

## 8. 结论与动作

1. **层 C 除名。** spec referenced section 层 C 从「候选」改为「已测·否决」, referenced section 对外答法中的
   "near-certainty carry (the only price band that tests net-positive market-wide)" 一句
   **必须删或改** —— 它现在有反证 (聚类后不显著)。
2. **260726 报告加限定 (已改, 见 referenced section)。** 报告 referenced section 补上市场级聚类值 —— 与它 referenced section 对总量
   已经在用的方法一致 ——「唯一为正的价带」改为「唯一没有明确为负的价带」。
   判据公开的含义就是不利结果也公布 (spec referenced section) —— 这正是那种结果。
3. **不进 paper forward。** 不写策略, 不占底仓, 不进产品材料。
4. **留下的线索**: (a) crypto 品类 +1.41pp 尾部优势, n=755, 单独立项才有意义;
   (b) **反向假设** —— 实证尾部率系统性高于隐含, 意味着近确定区的**卖方**(或 No 侧买方)
   可能才是正 edge 侧, 且与 referenced section FLB 实测「edge 只在 No 价 <0.90 端」同向。这条比层 C
   本身更值得测, 但它是一个**新假设需要新的预登记**, 不能拿本次数据回头拟合。
5. **四层收益结构变化**: 层 A (做市补贴, 8 月底判决) + 层 B (行为溢价, 在产) + 层 D (执行差,
   F1 最高杠杆) 三层不变; 层 C 出局。**这不降低组合目标, 它移除的是一个未验证的加数。**
